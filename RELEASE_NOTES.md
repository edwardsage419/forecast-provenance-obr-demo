# Version 0.1.0: offline OBR demonstration

Initial standalone research demonstration intended for independent manual reproduction. The program uses the Python standard library only, recalculates selected forecast errors, shows a controlled omission relative to a researcher-curated reference, and explicitly preserves UNKNOWN claims for historical completeness, source authentication and independent durability.

The repo-level materials are separate from Forecast Trust Core. See `LICENSE_SCOPE.md` for the strictly limited MIT code scope and `OBR_DATA_ATTRIBUTION.md` for OBR information reuse.

This version makes no independent mandatory-universe or historical authentication claim and does not establish any protocol or commercial production status.
