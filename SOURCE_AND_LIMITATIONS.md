# Public sources, scope and limitations

These are manually transcribed public OBR values. The project has not independently acquired authenticated original source bytes, authenticated revisions, or a rule-derived mandatory publication universe.

The example fixes a **March 2026 observation vintage of 2025 real GDP growth at 1.4%**, using OBR's spring 2026 public data. This is a revisable observation, not timeless ground truth. The OBR's historical report pages, open data archive and forecast FAQ include these materials:

* https://obr.uk/report/medium-term-forecasts/
* https://obr.uk/data/
* https://obr.uk/faq/where-can-i-find-your-latest-forecasts/

The October 2024 report was subject to a November 2024 correction notice. The indicated correction items did not list Annex A Table A.1, but authenticated before-and-after report bytes are **not** in this demonstration:

* https://obr.uk/docs/dlm_uploads/Correction-slip-October-2024.pdf

For the four selected forecasts: `(0.5 + 0.6 + 0.4 + 0.1) / 4 = 0.4` percentage points mean absolute error. For the deliberately reduced three-row sample, the mean is `0.5` percentage points. These repeated forecast editions share one target and are statistically dependent.
